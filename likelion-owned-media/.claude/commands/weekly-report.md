# /weekly-report — 주간 성과 요약

## 역할
GA4 등 데이터를 받아 주간 성과 요약 MD를 `05_reports/` 에 생성한다.

## Claude Code 실행 지시

```
다음 데이터로 주간 성과 리포트를 작성해줘.

기간: [YYYY-MM-DD ~ YYYY-MM-DD]
데이터: [아래에 붙여넣기]

---
[GA4 / 스프레드시트 데이터 붙여넣기]
---

파일명: [YYYY-MM-DD]_weekly-report.md
저장 위치: 05_reports/

포함 요소:
1. 핵심 요약 (3줄 이내)
2. 지표 현황 표
   - 오가닉 트래픽 (목표: 19,500/월 기준 주간 환산)
   - CVR (목표치 대비)
   - 신규 발행 콘텐츠 수
   - 상위 5개 유입 페이지
3. 전주 대비 변화 (▲/▼/→)
4. 원인 분석 (잘된 것 / 못된 것)
5. 다음 주 액션 아이템 (우선순위 포함)
```
