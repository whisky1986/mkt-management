# /new-content — 콘텐츠 초안 생성

## 역할
채널에 맞는 콘텐츠 초안을 `02_content/drafts/` 에 생성한다.

## 입력 (Claude에게 제공할 정보)
- **채널**: blog / youtube / threads / x
- **주제**: [자유 입력]
- **타겟 키워드**: [주요 1~3개]
- **독자 페르소나**: [예: 비전공자 취업 준비생, 25세]
- **목적**: 유입 / 전환 / 인지

## Claude Code 실행 지시

```
다음 조건으로 콘텐츠 초안을 작성해줘:

채널: [채널명]
주제: [주제]
타겟 키워드: [키워드]
독자: [페르소나]
목적: [유입/전환/인지]

파일명: [채널]_[주제-요약]_draft.md
저장 위치: 02_content/drafts/

포함 요소:
- [ ] 제목 3개 후보 (SEO 고려)
- [ ] 메타디스크립션 (150자 이내)
- [ ] 본문 구조 (H2/H3 아웃라인)
- [ ] 본문 초안
- [ ] CTA (Call-to-Action) 문구 2개
- [ ] 내부 링크 기회 목록
- [ ] 발행 전 체크리스트
```

## 채널별 어체 가이드

| 채널 | 어체 | 톤 |
|---|---|---|
| blog | 해요체 | 전문성 + 친근함 |
| youtube | 구어체 | 에너지·동기부여 |
| threads | 반말 | 솔직·일상적 |
| x | 해요체/합니다 | 전문성·인사이트 |
